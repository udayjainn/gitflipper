## Create Your First Profile

A **profile** is a saved Git identity — a name, email, and optional SSH key.

**Most people need two profiles:**
- **Work** — your company email and work SSH key
- **Personal** — your personal email and personal SSH key

**To create a profile:**

1. Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`)
2. Type **"GitFlip: Create Profile"**
3. Follow the 5-step wizard:
   - **Profile name** — something descriptive like "Work" or "Personal"
   - **Git name** — the name shown on commits (e.g., "Jane Doe")
   - **Git email** — the email shown on commits (e.g., "jane@company.com")
   - **SSH key** — select from detected keys, browse, or skip
   - **Directories** — folders where this profile should auto-activate

The wizard will auto-detect your current Git settings and SSH keys to speed things up.
